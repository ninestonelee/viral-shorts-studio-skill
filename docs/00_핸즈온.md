# 핸즈온 — 설치부터 발행 문구까지 한 번에 (약 40분)

> 이 문서 하나만 따라 하면 됩니다. 연습용 가상 상품 "무선 미니 청소기"로 대본 3편을 만들고, 검사를 통과시키고, 발행 문구까지 손에 쥐어 봅니다.
> 터미널을 처음 열어 보는 분도 괜찮아요. 한 줄 치고, 화면을 확인하고, 다음 줄로 갑니다.

---

## 0. 준비물 확인 (2분)

터미널(Mac은 "터미널" 앱, Windows는 "PowerShell")을 열고 아래 두 줄을 차례로 쳐 보세요.

```bash
claude --version
python3 --version
```

둘 다 버전 숫자가 나오면 준비 끝이에요. (Windows에서 `python3`이 안 되면 `python`으로 바꿔 치세요.)

## 1. 설치 (5분)

### Mac
```bash
cd ~/Documents
git clone https://github.com/ninestonelee/viral-shorts-studio-skill.git
cd viral-shorts-studio-skill
bash scripts/install.sh
```

### Windows (PowerShell)
```powershell
cd ~\Documents
git clone https://github.com/ninestonelee/viral-shorts-studio-skill.git
cd viral-shorts-studio-skill
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```

네 줄의 뜻은 이래요. 내 문서 폴더로 가서, 저장소를 내려받고, 그 폴더로 들어가서, 설치 스크립트를 실행한다.

**이 화면이 나오면 성공입니다.**
```
b2b        B2B · 리드 · 컨설팅 — 의사결정자 대상. 사례 숫자 + 1문장 진단 + 상담 CTA.
brand      브랜드 · 창업자 스토리 — 사람·과정·실패·기록. 판매 압박 없음. 1인칭은 실제 경험만.
course     강의 · 모집 · 세미나 — 대상 한정 + 결과 약속은 근거 있는 것만 + 마감.
health     건강정보 · 운동/습관 — 정보형. 효능 단정 금지, 출처 의무, 의료 대체 암시 금지. 상품 있으면 운동 보조까지만.
local      지역 매장 · 오프라인 — 위치·현장·사람. 방문 CTA. 지도 링크.
service    서비스 · 앱 · SaaS — 화면 녹화 중심. 3초 안에 결과 화면. 가입/체험 CTA.
shop-aff   쇼핑 · 제휴(쿠팡 파트너스) — 남의 상품. 대가성 문구 필수. 소싱 2기준(효과 가시·후기 다수).
shop-own   쇼핑 · 자사 상품 — 내가 파는 상품. 1차 리뷰가 리서치 재료. 판매자 제작 표기.
```

이 8줄이 "장르 팩"이에요. 팩 하나에 그 장르의 질문·훅 유형·금지어·표기 문구가 다 들어 있습니다. 오늘은 쿠팡 제휴 상품을 다루니 `shop-aff`를 씁니다.

git이 없다고 나오면 GitHub 페이지(https://github.com/ninestonelee/viral-shorts-studio-skill) 오른쪽 위 녹색 **Code → Download ZIP**으로 받아 압축을 풀고, 그 폴더에서 설치 스크립트만 실행하세요. 결과는 같아요.

## 2. 준비 두 줄 (1분)

이제부터 명령은 전부 터미널에서 칩니다. 매번 긴 주소를 치지 않도록 줄임말 두 개를 만들어 둡니다. (터미널을 닫으면 사라지니, 다시 열면 이 두 줄만 한 번 더.)

작업할 폴더도 하나 만들어 들어갑니다.
```bash

```

## 3. 배치 시작 (2분)

"배치"는 상품 하나로 만드는 대본 묶음이에요. `연습1`이라는 이름으로 시작합니다.

```bash
python3 $V -b 연습1 init "미니 청소기 연습" --pack shop-aff --count 3 --subject "무선 미니 청소기" --url https://example.com/p/1 --rel affiliate --notes "차량용, 노즐 1.5cm, 충전 20분"
```
```
배치 생성: /Users/홍길동/Documents/shorts/연습1 (팩 shop-aff, 3편)
```

| 적은 것 | 뜻 |
|---|---|
| `-b 연습1` | 연습1 폴더에서 작업한다 |
| `--pack shop-aff` | 쿠팡 제휴 팩 |
| `--count 3` | 대본 3편 |
| `--subject` | 상품 이름 |
| `--url` | 상품 링크 (발행 문구에 자동으로 들어감) |
| `--rel affiliate` | 나와 상품의 관계가 "제휴". 그래서 "쿠팡 파트너스…" 표기가 자동으로 붙어요 |
| `--notes` | 메모. 대본 쓸 때 참고 |

## 4. 소싱 질문 — 이 상품, 만들어도 될까? (3분)

쇼츠에서 가장 많은 실수는 안 될 상품에 시간을 쓰는 거예요. 그래서 시작하자마자 세 가지를 묻습니다. `y`는 예, `n`은 아니오.

```bash
python3 $V -b 연습1 sourcing "visible=y,reviews=y,rights=y" --show "시트 틈에 노즐이 들어가 부스러기를 빨아들이는 장면"
```
```
✔ 효과가 눈에 확 보이는가? (버튼 누르니 커튼이 스르륵)
✔ 후기가 많은가? (없으면 볼 데이터가 없다)
✔ 쓸 소재가 있는가? (상품 상세 이미지는 판매자 권리 → 캡처 사용 범위 확인, 남의 영상 금지)

소싱 통과 → 시트 틈에 노즐이 들어가 부스러기를 빨아들이는 장면
```

`--show` 뒤에는 **영상 첫 3초에 실제로 보일 장면**을 한 줄로 적어요. 이게 안 떠오르면 그 상품은 쇼츠로 어렵습니다.

**한 번 일부러 실패시켜 보세요.** 첫 질문만 `n`으로 바꿉니다.
```bash
python3 $V -b 연습1 sourcing "visible=n,reviews=y,rights=y" --show "x"
```
```
✘ 효과가 눈에 확 보이는가? (버튼 누르니 커튼이 스르륵)
✔ 후기가 많은가? (없으면 볼 데이터가 없다)
✔ 쓸 소재가 있는가? (상품 상세 이미지는 판매자 권리 → 캡처 사용 범위 확인, 남의 영상 금지)

중단: ✘ 항목이 있어요. 소재를 바꾸거나 대체(alt) 방안을 정하세요.
```

하나라도 ✘면 여기서 멈춰요. 넘어가는 옵션은 일부러 없습니다. 확인했으면 다시 `y` 세 개로 통과시켜 두세요.
```bash
python3 $V -b 연습1 sourcing "visible=y,reviews=y,rights=y" --show "시트 틈에 노즐이 들어가 부스러기를 빨아들이는 장면"
```

## 5. 리서치 반영 (2분)

대본은 상상으로 쓰지 않아요. 실제 리뷰·커뮤니티에서 사람들이 한 말("발화")을 출처와 함께 모아서 씁니다. 실제 수업에서는 Claude가 웹을 검색해 모아 오고, 오늘은 미리 만들어 둔 예제를 넣습니다.

```bash
python3 $V -b 연습1 ingest research $E/research_raw.json
```
```
리서치 반영: 발화 5건(출처 없음 0), 트렌드 2건
```

**"출처 없음 0"**이 중요해요. 출처 없는 발화가 있으면 경고가 나고, 그걸로 쓴 대본에는 `[확인 필요]`가 붙어 승인이 안 됩니다.

예제 파일을 열어 보면 발화 하나가 이렇게 생겼어요.
```json
{"quote": "차 안 과자 부스러기는 손으로 털어도 시트 틈에 남는다", "src": "쿠팡 리뷰 #88213", "lv": 0, "hook": "시트 틈 부스러기, 손으로 털지 마세요"}
```
`lv`는 출처 등급이에요. 0은 리뷰 원문, 1은 커뮤니티 글, 2는 기사, 3은 미확인.

## 6. 대본 3편 넣고 검사 (5분)

대본도 마찬가지로 실제 수업에서는 Claude가 쓰고, 오늘은 예제를 넣습니다.

```bash
python3 $V -b 연습1 ingest plans $E/plans_raw.json
```
```
플랜 3편 반영
```

**여기가 이 도구의 핵심이에요. 검사를 돌립니다.**
```bash
python3 $V -b 연습1 check
```
```
[1편] ✘ 불편형 · 추정 19초 · 훅 린트 38점(The Question)
  제목: 차 시트 틈 과자 부스러기, 손으로 털지 마세요 (3가지 이유)
  ✘ 장면: 1번 컷 소재 없음
  △ 추정 19초 (목표 25~35)
  △ 훅 린트 38점(WEAK) — 약한 곳: 손실·위험 → 지금 방식을 유지하면 잃는 것 한 줄 [보정 전 휴리스틱]
  △ 썸네일이 제목과 겹침: 부스러기,시트,틈
  △ 장면: 1번 컷 6.8초 — 핵심 등장이 3초를 넘길 수 있음
  △ 장면: 소재 미지정 4컷 (검정 화면)

[2편] ✘ 상황극형 · 추정 20초 · 훅 린트 40점(미분류)
  ...

[3편] ✘ 랭킹형 · 추정 21초 · 훅 린트 42점(The Question)
  ...

오류 있음 — 발행 불가
```

읽는 법은 두 가지만 알면 됩니다.

- **✘는 오류.** 고치지 않으면 승인도 발행도 안 돼요. 지금은 "1번 컷 소재 없음" 하나뿐인데, 아직 사진을 안 넣었으니 당연한 거예요. 8단계에서 사라집니다.
- **△는 경고.** 읽고 내가 판단해요. "추정 19초, 목표 25~35"는 대사가 짧다는 뜻이고, "썸네일이 제목과 겹침"은 썸네일 글자와 제목이 같은 말을 한다는 뜻이에요.

"훅 린트 38점"은 첫 문장의 힘을 다섯 가지(구체성·호명·손실위험·호기심·간결성)로 본 점수예요. "[보정 전 휴리스틱]"은 아직 실제 조회수와 맞춰 보지 않은 참고 점수라는 표시입니다.

## 7. 첫 문장 고쳐 보기 (5분)

첫 문장만 따로 점수를 볼 수 있어요. 원래 문장을 넣어 봅니다.
```bash
python3 $V lint "차 시트 틈에 낀 과자 부스러기, 손으로 털어도 안 나오죠?"
```
```
"parts": {"구체성": 34, "호명": 26, "손실·위험": 22, "호기심": 59, "간결성": 100},
"v": 38, "band": "WEAK", "formula": "The Question",
"weak": "손실·위험", "fix": "지금 방식을 유지하면 잃는 것 한 줄"
```
"손실·위험"이 22점으로 가장 약하고, 처방은 "안 하면 잃는 것을 한 줄 넣어라"예요.

누구인지(40대), 숫자(1주일), 잃는 말(잃는 게)을 넣어서 다시 봅니다.
```bash
python3 $V lint "아이 키우는 40대 분들, 시트 틈 부스러기 1주일 방치하면 잃는 게 있어요. 뭘까요?"
```
```
"parts": {"구체성": 78, "호명": 76, "손실·위험": 62, "호기심": 76, "간결성": 100},
"v": 72, "band": "STRONG"
```
38점에서 72점으로 올랐어요. 이제 **내 문장을 하나 만들어 점수를 보세요.** 세 번 고쳐 보는 것이 목표예요.

점수가 높은데 어색한 문장이면 사람 판단이 이깁니다. 점수는 참고예요.

## 8. 사진 등록하고 컷에 붙이기 (5분)

연습이니 빈 파일 두 개를 사진 대신 만듭니다. (실제로는 직접 찍은 사진을 `연습1/assets/`에 넣으면 돼요.)
```bash
printf 'x' > 연습1/assets/nozzle.jpg
printf 'x' > 연습1/assets/box.jpg
```

등록할 때는 **역할**과 **권리**를 꼭 적어요.
```bash
python3 $V -b 연습1 asset 연습1/assets/nozzle.jpg --role "사용 장면" --rights "직접 촬영"
python3 $V -b 연습1 asset 연습1/assets/box.jpg --role 정면 --rights "판매자 제공"
```
```
소재 a2d7e: 연습1/assets/nozzle.jpg · 사용 장면 · 직접 촬영
소재 ab271: 연습1/assets/box.jpg · 정면 · 판매자 제공
```

앞의 `a2d7e` 같은 다섯 글자가 소재 번호예요. **여러분 화면에는 다른 글자가 나옵니다.** 그 글자를 아래에 넣어 1편의 네 컷에 붙입니다.
```bash
python3 $V -b 연습1 scene --plan 1 "1=a2d7e,2=a2d7e,3=ab271,4=a2d7e"
```
```
[1편] ✔ 불편형 · 추정 19초 · 훅 린트 38점(The Question)
  제목: 차 시트 틈 과자 부스러기, 손으로 털지 마세요 (3가지 이유)
  △ 추정 19초 (목표 25~35)
  △ 훅 린트 38점(WEAK) — 약한 곳: 손실·위험 → 지금 방식을 유지하면 잃는 것 한 줄 [보정 전 휴리스틱]
  △ 썸네일이 제목과 겹침: 부스러기,시트,틈
  △ 장면: 1번 컷 6.8초 — 핵심 등장이 3초를 넘길 수 있음
```

✘가 ✔로 바뀌었어요. 권리를 `미확인`으로 등록한 사진을 컷에 붙이면 다시 ✘가 납니다. 남의 사진을 쓰지 않는다는 규칙이 코드 안에 들어 있는 거예요.

## 9. 내보내기와 발행 문구 (5분)

```bash
python3 $V -b 연습1 export --plan 1
```
```

  → 연습1/exports/factory_1.md
  → 연습1/exports/script_045_1.txt
  → 연습1/exports/publish_1.md
  → 연습1/exports/research.md
  → 연습1/exports/content_plan.md
```

오늘 쓰는 파일은 **factory_1.md** 하나예요. 열어 보세요.
```bash
cat 연습1/exports/factory_1.md
```

## 10. 승인과 게이트 (3분)

대본이 마음에 들면 승인 기록을 남깁니다.
```bash
python3 $V -b 연습1 approve --plan 1
```
```
굿 기록 — 1편. 이제 gates → upload
```
검사에 ✘가 남아 있으면 승인이 거부돼요. 그래서 8단계를 건너뛰면 여기서 막힙니다.

마지막으로 발행 전 점검 12개를 봅니다.
```bash
python3 $V -b 연습1 gates --plan 1 --video 연습1/renders/1.mp4
```
```
✔ 굿 승인 기록(approve)
✔ 플랜 검사 오류 0
✔ 장면표 검사 오류 0
✔ [확인 필요] 0
✔ 소재 권리 미확인 0 (현재 0)
✔ 다른 편과 대사 유사도 < 50% (최대 19% · ...)
✔ 이 편은 아직 업로드 안 함/결과 확정
✔ 오늘 업로드 0/2
✔ 직전 업로드와 6시간 간격
✘ 영상 파일 존재
✘ 세로·180초 이하 (Shorts 조건 · ffprobe 없음/실패)
✘ YouTube 토큰(VSS_YT_TOKEN) 있음

막힘 — ✘ 항목 해결 전 업로드 금지
```
12개 중 9개 ✔, 영상 관련 3개 ✘. **이게 오늘의 정상 화면이에요.** 영상이 아직 없으니까요. 자동 업로드 기능은 수업에서 쓰지 않습니다. 9단계의 발행 문구를 복사해 직접 올리는 게 더 안전하고 빨라요.

## 11. 48시간 뒤에 할 일 (숙제)

영상을 올렸다면 48시간 뒤 유튜브 스튜디오에서 조회수와 "계속 시청 비율"을 보고 넣습니다. 연습으로 가상의 숫자를 넣어 볼게요.
```bash
python3 $V -b 연습1 perf --plan 1 --v48 900 --stay 58 --click 7
python3 $V -b 연습1 perf --plan 2 --v48 2400 --stay 66 --click 21 --conv 1
python3 $V -b 연습1 perf --plan 3 --v48 400 --stay 41 --click 2
python3 $V -b 연습1 winner
```
```
n=3 승자: 카시트 밑 청소 포기했던 분, 20분이면 차 한 대 끝 (상황극형) 점수 4604
      패자: 미니 청소기 흡입력 약하다는 후기, 부스러기 1분 테스트 결과 (랭킹형) 점수 604

[규칙 후보] 이 소재는 상황극형 훅, 1번 컷 7.5초가 48h 기준 우세. 다음 배치에서 재현되면 규칙으로 올린다 (R-007).
```
어떤 훅 유형이 이겼는지 알려 줘요. "규칙 후보"는 아직 규칙이 아니에요. 한 번 이긴 건 우연일 수 있어서, 다음 배치에서도 이기면 그때 규칙으로 올립니다.
