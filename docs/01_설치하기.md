# 01. 설치하기

> 걸리는 시간: 5분. 터미널(검은 창)을 처음 열어 보는 분도 따라올 수 있게 썼어요.
> 막히면 [04_자주묻는질문.md](04_자주묻는질문.md)를 먼저 보고, 그래도 안 되면 수업 채팅방에 **화면을 캡처해서** 올려 주세요.

## 0. 설치 전에 두 가지만 확인

### Claude Code가 있나요?
터미널을 열고 아래를 입력한 뒤 엔터.
```bash
claude --version
```
`2.x.x` 같은 숫자가 나오면 됩니다. "command not found"가 나오면 Claude Code부터 설치해야 해요. 수업 1차시 자료 "Claude Code 설치"를 따라 하세요.

### Python이 있나요?
```bash
python3 --version        # Mac
python --version         # Windows
```
`Python 3.9` 이상이면 됩니다. Mac은 기본으로 들어 있고, Windows는 없으면 python.org에서 받아 설치할 때 **"Add Python to PATH" 체크**를 꼭 켜 주세요.

터미널 여는 법이 기억 안 나면: Mac은 `command + space` 눌러 "터미널" 입력, Windows는 시작 버튼 눌러 "PowerShell" 입력.

## 1. 저장소 내려받기

두 가지 방법 중 편한 걸 고르세요. 결과는 같아요.

### 방법 A. git으로 받기 (추천)
```bash
cd ~/Documents
git clone https://github.com/ninestonelee/viral-shorts-studio-skill.git
cd viral-shorts-studio-skill
```
첫 줄은 "내 문서 폴더로 가라", 둘째 줄은 "저장소를 복사해 와라", 셋째 줄은 "그 폴더로 들어가라"는 뜻이에요.

### 방법 B. ZIP으로 받기
1. 브라우저에서 https://github.com/ninestonelee/viral-shorts-studio-skill 을 엽니다.
2. 오른쪽 위 녹색 **Code** 버튼 → **Download ZIP**.
3. 받은 파일을 더블클릭해 압축을 풉니다. `viral-shorts-studio-skill-main` 폴더가 생겨요.
4. 그 폴더를 "내 문서" 안으로 옮기고, 터미널에서 그 폴더로 들어갑니다.
   ```bash
   cd ~/Documents/viral-shorts-studio-skill-main
   ```

## 2. 설치 스크립트 실행

폴더 안에 들어와 있는 상태에서:

**Mac**
```bash
bash scripts/install.sh
```

**Windows (PowerShell)**
```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```

이 스크립트가 하는 일은 하나예요. Claude Code가 스킬을 찾는 자리인 `~/.claude/skills/` 안에 **이 폴더로 가는 바로가기**를 만듭니다. 그래서 나중에 저장소를 업데이트하면 스킬도 같이 새 버전이 됩니다.

### 성공 화면
```
설치 완료 → /Users/홍길동/.claude/skills/viral-shorts-studio
확인 중...
b2b        B2B · 리드 · 컨설팅 — 의사결정자 대상. 사례 숫자 + 1문장 진단 + 상담 CTA.
brand      브랜드 · 창업자 스토리 — 사람·과정·실패·기록. 판매 압박 없음. 1인칭은 실제 경험만.
course     강의 · 모집 · 세미나 — 대상 한정 + 결과 약속은 근거 있는 것만 + 마감.
health     건강정보 · 운동/습관 — 정보형. 효능 단정 금지, 출처 의무, 의료 대체 암시 금지. 상품 있으면 운동 보조까지만.
local      지역 매장 · 오프라인 — 위치·현장·사람. 방문 CTA. 지도 링크.
service    서비스 · 앱 · SaaS — 화면 녹화 중심. 3초 안에 결과 화면. 가입/체험 CTA.
shop-aff   쇼핑 · 제휴(쿠팡 파트너스) — 남의 상품. 대가성 문구 필수. 소싱 2기준(효과 가시·후기 다수).
shop-own   쇼핑 · 자사 상품 — 내가 파는 상품. 1차 리뷰가 리서치 재료. 판매자 제작 표기.

위에 장르 팩 8줄이 보이면 성공이에요. Claude Code를 새로 열면 /viral-shorts-studio 스킬이 보입니다.
```

이 8줄이 "장르 팩"이에요. 쇼츠의 장르별 규칙 묶음이라고 생각하시면 됩니다. 수업에서는 주로 `shop-aff`(쿠팡 제휴)와 `shop-own`(내 상품)을 씁니다.

## 3. Claude Code에서 확인

Claude Code를 **새로** 엽니다(이미 열려 있었다면 닫고 다시). 그리고 `/`를 입력하면 스킬 목록이 뜨는데, 거기에 `viral-shorts-studio`가 있으면 끝이에요.

또는 그냥 이렇게 물어보세요.
```
viral-shorts-studio 스킬 설치됐어? 장르 팩 목록 보여줘
```
Claude가 위의 8줄을 다시 보여 주면 정상입니다.

## 4. 업데이트하는 법 (나중에)

수업 중에 스킬이 고쳐지면 안내할 거예요. 그때는 저장소 폴더에서 한 줄만 치면 됩니다.
```bash
cd ~/Documents/viral-shorts-studio-skill
git pull
```
바로가기로 연결돼 있어서 따로 다시 설치할 필요가 없어요. ZIP으로 받은 분은 새 ZIP을 받아 폴더를 통째로 바꾸고, 설치 스크립트를 한 번 더 실행하세요.

## 5. 지우고 싶을 때

바로가기 하나만 지우면 됩니다. 저장소 폴더는 그대로 두어도 되고 지워도 돼요.
```bash
rm ~/.claude/skills/viral-shorts-studio        # Mac
```
```powershell
Remove-Item "$env:USERPROFILE\.claude\skills\viral-shorts-studio"   # Windows
```

## 자주 나오는 설치 오류

| 화면에 보이는 말 | 뜻 | 해결 |
|---|---|---|
| `command not found: git` | git이 없어요 | 방법 B(ZIP)로 받으세요 |
| `command not found: python3` | Python이 없어요 | Mac: `xcode-select --install` 후 재시도. Windows: python.org에서 설치 |
| `이미 같은 이름의 폴더가 있어요` | 예전에 설치한 흔적 | 안내된 폴더를 지우고 다시 실행 |
| `Permission denied` | 실행 권한 없음 | 앞에 `bash `를 붙여 `bash scripts/install.sh`로 |
| Windows에서 `실행할 수 없습니다. 스크립트 실행이 비활성화` | PowerShell 보안 설정 | 명령 앞에 적힌 `-ExecutionPolicy Bypass`를 빠뜨리지 않았는지 확인 |
| 한글 폴더명 때문에 깨짐 | 경로에 한글 | 저장소를 `Documents` 같은 영문 폴더에 두세요 |
