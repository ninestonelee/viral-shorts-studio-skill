# 03. 실습 — 90분에 쇼츠 3편 기획 끝내기

> 수업 시간에 강사와 함께 따라 하는 순서입니다. 혼자 복습할 때도 이 순서대로 하면 됩니다.
> 목표: **내 상품(또는 쿠팡 제휴 상품) 하나로 대본 3편을 만들고, 검사를 전부 통과시키고, 발행 문구까지 손에 쥐기.**

## 준비 (수업 전에 해 두면 좋아요)

- [ ] [01_설치하기](01_설치하기.md) 완료 — `python3 ~/.claude/skills/viral-shorts-studio/scripts/vss.py packs`(파이썬 없는 분은 `node …/vss.js packs`) 치면 8줄이 나오는 상태
- [ ] 쇼츠로 만들 상품 하나 정하기. 처음엔 **쿠팡 제휴 상품** 중 "효과가 눈에 보이는 것"이 쉬워요. (예: 틈새 청소기, 자동 커튼, 접이식 상자) 화장품·건강식품은 효과가 안 보여서 첫 실습엔 어려워요.
- [ ] 그 상품의 쿠팡 링크, 그리고 사진 2~3장 (직접 찍은 것 또는 판매자 제공 이미지. 남의 영상 금지)

## 1교시 (0~30분) — 멈출 줄 아는 연습: 소싱과 리서치

### 1-1. 배치 시작 (5분)
Claude Code를 열고 작업 폴더로 간 뒤, 이렇게 말합니다.
```
/viral-shorts-studio 쿠팡 제휴로 "[상품명]" 쇼츠 3편 기획을 시작하자. 링크는 [URL]. 배치 폴더는 shorts/1차로.
```
Claude가 팩을 추천하면서 이유를 말해 줄 거예요. `shop-aff`가 맞다고 하면 그대로 진행.

**직접 쳐 보고 싶은 분**은 터미널에서:
```bash
V=~/.claude/skills/viral-shorts-studio/scripts/vss.py
python3 $V -b shorts/1차 init "[상품명] 1차" --pack shop-aff --count 3 --subject "[상품명]" --url [URL] --rel affiliate
```

### 1-2. 소싱 질문 (5분) — 가장 중요한 5분
Claude가 세 질문을 던집니다. **솔직하게** 답하세요.
- 효과가 눈에 확 보이는가?
- 후기가 많은가? (30건 이상)
- 쓸 소재가 있는가?

하나라도 ✘면 멈추고 다른 상품으로 바꿉니다. 옆 사람 상품이 ✘로 멈추는 걸 보는 것도 공부예요. **"안 되는 걸 빨리 아는 것"이 이 도구의 첫 번째 가치**입니다.

### 1-3. 리서치 (20분)
Claude에게 리서치를 시킵니다.
```
리서치 해줘. 쿠팡 리뷰와 네이버 카페 글에서 불편한 말 5개 이상, 출처 꼭 붙여서.
```
Claude가 검색해서 발화 5개 이상을 출처와 함께 가져오면 반영까지 해 줍니다. 결과 화면에서 이 줄을 확인하세요.
```
리서치 반영: 발화 5건(출처 없음 0), 트렌드 2건
```
**"출처 없음 0"**이어야 합니다. 1 이상이면 Claude에게 "출처 없는 건 빼거나 lv 3으로 표시해"라고 합니다.

> 강사 메모: 시간이 부족한 반은 리서치를 생략하고 예제(`examples/sample_batch/research_raw.json`)를 반영해 2교시로 넘어갑니다. 단, 예제는 가상의 상품이라 자기 상품 대본과 섞이지 않게 별도 배치(`연습1`)로.

## 2교시 (30~60분) — 쓰고, 검사하고, 고치기

### 2-1. 대본 3편 (10분)
```
리서치로 대본 3편 써줘. 편마다 훅 유형 다르게.
```
Claude가 대본을 쓰고 바로 `check`까지 돌립니다. 화면에 ✘와 △가 보일 거예요.

### 2-2. 검사 읽는 법 (10분)
강사가 한 명의 화면을 띄워 함께 읽습니다. 꼭 짚을 세 가지:
1. **✘ "1번 컷 소재 없음"** — 아직 사진을 안 넣어서 나는 오류. 정상.
2. **△ "추정 19초 (목표 25~35)"** — 대사가 짧다. 한 문장 더.
3. **△ "훅 린트 38점(WEAK) — 약한 곳: 손실·위험"** — 첫 문장에 "안 하면 잃는 것"이 없다.

### 2-3. 첫 문장 고치기 대회 (10분)
각자 1편의 첫 문장을 세 번 고쳐 가며 점수를 봅니다.
```bash
python3 $V lint "원래 첫 문장"
python3 $V lint "고친 첫 문장"
```
예시:
| 첫 문장 | 점수 |
|---|---|
| 차 시트 틈에 낀 과자 부스러기, 손으로 털어도 안 나오죠? | 38 WEAK |
| 아이 태우는 분들, 시트 틈 부스러기 그대로 두면 곰팡이 냄새 납니다. 왜일까요? | 40 WEAK (거의 안 올랐어요!) |
| 부모님 차 시트 틈 부스러기, 그대로 두면 3개월 뒤 곰팡이 냄새로 후회합니다. 왜일까요? | 67 WORKABLE |
| 아이 키우는 40대 분들, 시트 틈 부스러기 1주일 방치하면 잃는 게 있어요. 뭘까요? | 72 STRONG |

둘째 줄이 재미있는 부분이에요. 사람이 보기엔 꽤 나아진 문장인데 점수는 2점밖에 안 올랐습니다. 린트는 "분들"을 호명으로 세지 않고, "곰팡이 냄새"를 손실로 세지 않기 때문이에요. 셋째·넷째 줄처럼 **누구인지(부모님·40대), 숫자(3개월·1주일), 잃는 말(후회·잃는)**을 또렷이 넣어야 점수가 뜁니다.

점수가 오른 사람은 어디가 올랐는지(호명? 손실·위험?) 말해 봅니다. **점수는 참고일 뿐**이라는 것도 같이 확인해요. 점수가 높은데 어색한 문장이면 사람 판단이 이깁니다.

고친 문장은 Claude에게 "1편 첫 문장을 이걸로 바꾸고 다시 검사해"라고 하면 됩니다.

## 3교시 (60~90분) — 소재 붙이고 발행 준비

### 3-1. 소재 등록 (10분)
준비한 사진을 `shorts/1차/assets/`에 넣고 Claude에게:
```
assets 폴더 사진 등록해줘. nozzle.jpg는 사용 장면·직접 촬영, box.jpg는 정면·판매자 제공.
```
그리고 1편 장면표에 붙이기:
```
1편 장면표: 1·2컷은 nozzle, 3컷은 box, 4컷은 nozzle로.
```
`check`에서 ✘가 전부 사라지는 걸 확인합니다.
```
[1편] ✔ 불편형 · 추정 27초 · 훅 린트 61점(The Warning)
```

### 3-2. 내보내기와 발행 문구 (10분)
```
1편 내보내고 발행 문구 보여줘.
```
`exports/factory_1.md`를 열어 봅니다. Hook / Body / CTA / Shots가 영상 편집 순서 그대로예요. 이걸 캡컷이나 브루에 붙여 영상을 만듭니다(영상 제작은 다음 차시).

발행 문구에서 **"쿠팡 파트너스 활동의 일환으로 수수료를 제공받습니다"**가 유튜브·틱톡·인스타 세 곳에 다 들어갔는지 눈으로 확인합니다.

### 3-3. 승인과 게이트 (5분)
대본이 마음에 들면:
```
1편 승인(굿) 해줘.
```
그리고 게이트를 봅니다.
```
1편 발행 게이트 보여줘.
```
12개 중 9개 ✔, 영상 관련 3개 ✘가 정상이에요. 영상이 생기면 그 셋도 ✔가 됩니다.

### 3-4. 마무리 (5분)
각자 세 줄로 적어 공유합니다.
- 내 상품은 소싱을 통과했나, 무엇 때문에 막혔나
- 첫 문장 점수가 몇에서 몇으로 올랐나
- 다음 차시 영상 만들 때 쓸 파일 경로 (`shorts/1차/exports/factory_1.md`)

## 숙제

1. 48시간 뒤 유튜브 스튜디오 조회수를 넣고 승자를 봅니다. (영상을 올린 분만)
   ```
   1편 48시간 조회 900, 계속시청 58%, 클릭 7. 2편은 2400, 66%, 21, 전환 1. 승자 보여줘.
   ```
2. 다른 팩(`shop-own` 또는 `health`)으로 같은 상품을 시작해 보고, **금지어가 어떻게 달라지는지** 비교해 보세요. `health` 팩에 "개선"이라는 말을 넣으면 ✘가 나는 걸 직접 확인.

## 강사용 체크리스트

- [ ] 설치 확인은 수업 시작 전 10분에 끝낸다 (8줄 화면 캡처를 채팅방에 올리게)
- [ ] 소싱 ✘로 멈추는 수강생이 1명은 나오게 한다. 없으면 강사가 "화장품"으로 시연
- [ ] check 화면은 반드시 한 명 것을 공유 화면으로 함께 읽는다
- [ ] 린트 점수는 "참고"라고 세 번 말한다
- [ ] 업로드 기능은 쓰지 않는다. 발행 문구 복사로 끝
- [ ] 끝나면 `shorts/` 폴더를 통째로 백업하게 한다 (project.json 하나에 모든 게 들어 있음)
