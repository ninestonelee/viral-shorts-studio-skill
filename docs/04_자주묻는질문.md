# 04. 자주 묻는 질문

## 설치·실행

**Q. `/viral-shorts-studio`를 쳐도 목록에 안 나와요.**
Claude Code를 완전히 닫고 다시 열어 보세요. 스킬 목록은 시작할 때 읽습니다. 그래도 안 나오면 터미널에서 `ls ~/.claude/skills/`를 쳐서 `viral-shorts-studio`가 있는지 확인하세요. 없으면 설치 스크립트를 다시 실행합니다.

**Q. `python3: command not found`가 나와요.**
Windows는 `python3` 대신 `python`을 씁니다. Mac에서 이 말이 나오면 `xcode-select --install`을 한 번 실행한 뒤 다시 해 보세요.

**Q. `project.json 없음: ... — 먼저 vss.py init 실행`이라고 나와요.**
`-b` 뒤에 적은 배치 폴더 이름이 틀렸거나, 아직 `init`을 안 한 거예요. 지금 있는 폴더에서 `ls`를 쳐서 배치 폴더 이름을 확인하세요.

**Q. 한글 폴더 이름을 써도 되나요?**
배치 폴더(`-b 연습1`)는 한글 괜찮아요. 다만 저장소를 내려받는 위치는 `Documents` 같은 영문 폴더를 권합니다.

## 소싱·리서치

**Q. 소싱에서 ✘가 나서 멈췄어요. 그냥 넘어가면 안 되나요?**
넘어가는 옵션은 없어요. 일부러 그렇게 만들었습니다. "효과가 안 보이는 상품"은 쇼츠로 팔기 어렵고, "후기가 없는 상품"은 리서치할 재료가 없고, "소재가 없는 상품"은 남의 사진을 쓰게 됩니다. 셋 다 나중에 더 큰 시간을 잃어요. 다른 상품을 고르거나, 정말 대체 방법이 있으면 `alt`(△)로 답하고 그 방법을 "보여줄 것"에 적어 주세요.

**Q. 리서치에서 Claude가 리뷰를 못 찾아요.**
쿠팡 리뷰는 로그인이 필요해서 Claude가 직접 못 읽을 때가 있어요. 그럴 때는 리뷰 5개를 복사해서 Claude에게 붙여 주고 "이 리뷰로 리서치 JSON 만들어, 출처는 쿠팡 리뷰로"라고 하세요. 출처 등급은 0(원문)입니다.

**Q. `lv`(출처 등급)가 뭔가요?**
0 = 리뷰·문의 원문, 1 = 커뮤니티·후기, 2 = 기사·2차 인용, 3 = 미확인. 3이 붙은 발화로 만든 대본에는 `[확인 필요]` 표시가 들어가고, 그게 남아 있으면 승인이 안 돼요. 확인해서 지우거나 그 문장을 빼야 합니다.

## 검사

**Q. ✘와 △가 뭐가 다른가요?**
✘는 오류예요. 안 고치면 승인·발행이 막힙니다(금지어, 센 문장 개수, 표기 문구 누락, 권리 미확인 소재). △는 경고예요. 읽어 보고 "그래도 괜찮다"고 판단하면 두어도 됩니다(길이, 린트 점수, 태그 수).

**Q. "센 문장 2개 (1개여야)"라는 오류가 나요.**
대사 중 `strong: true`가 딱 하나여야 해요. 쇼츠는 25~35초라 센 문장이 둘이면 둘 다 묻힙니다. 하나만 고르세요.

**Q. 훅 린트 점수가 낮은데 제 문장이 더 좋은 것 같아요.**
그럴 수 있어요. 린트는 "숫자가 있나, 누구를 부르나, 잃는 것이 있나, 궁금하게 하나, 길이가 적당하나" 다섯 가지를 기계적으로 보는 거라서, 사람 귀에 좋은 문장을 놓칠 수 있습니다. 점수는 **막지 않아요**(△로만 나옵니다). 10편 넘게 올려서 조회수와 비교(`calibrate`)해 보기 전엔 참고용입니다.

**Q. "썸네일이 제목과 겹침"은 왜 경고인가요?**
유튜브에서 썸네일 글자와 제목이 같은 말을 하면 정보가 한 번 낭비돼요. 썸네일은 감정이나 장면, 제목은 내용. 서로 다른 말을 하게 하세요.

**Q. 금지어에 걸렸는데 꼭 써야 하는 말이에요.**
팩의 금지어는 과장·법 위반 가능성이 높은 말들이에요(최고, 1위, 치료, 완치…). 정말 근거가 있으면 "최고" 대신 "리뷰 1,240건 중 평점 4.8"처럼 **숫자로 바꾸는 쪽**이 거의 항상 더 셉니다. 팩 자체를 바꾸고 싶으면 `pack.json`을 배치 폴더에 복사해 `banned`를 편집하세요(`references/pack-schema.md`).

## 소재·장면표

**Q. 판매자 상세페이지 이미지를 캡처해서 쓰면 안 되나요?**
제휴 상품이면 판매자(또는 제조사)에 권리가 있어요. 쿠팡 파트너스 약관상 상품 이미지 사용 범위를 확인하고, 확인했으면 `--rights "판매자 제공"`으로 등록합니다. 확인 안 했으면 `미확인`으로 두되, 그 소재는 장면표에 못 넣어요(✘). 가장 안전한 건 직접 찍는 것.

**Q. 소재 번호(a8c10 같은 것)를 잊었어요.**
`project.json`을 열면 `assets` 아래에 있어요. 또는 Claude에게 "등록된 소재 목록 보여줘"라고 하세요.

## 발행·업로드

**Q. 유튜브 자동 업로드를 써도 되나요?**
수업에서는 쓰지 않아요. 기능은 들어 있지만 실제 계정으로 아직 검증하지 않았습니다. 발행 문구(`publish-text`)를 복사해서 유튜브 스튜디오에 직접 올리는 게 더 안전하고 빨라요.

**Q. 하루 2편 제한을 풀 수 있나요?**
`gates --cap 5 --gap 2`처럼 바꿀 수는 있어요. 그런데 이 제한은 "같은 틀 대본을 하루에 열 편 찍어 올리는" 일을 막으려고 둔 거예요. 유튜브는 그런 채널을 반복·대량 생산으로 보고 수익화를 막습니다. 바꾸기 전에 왜 바꾸는지 한 번 생각해 보세요.

**Q. 표기 문구("쿠팡 파트너스…")를 빼고 싶어요.**
빼는 옵션은 없어요. 제휴 수익이 있으면 표기는 법적 의무입니다(표시광고법). `--rel none`(판매 없음)으로 시작한 배치만 표기가 안 붙습니다.

## 성과

**Q. 48시간을 꼭 기다려야 하나요?**
비교할 때만요. 올린 지 1일 된 영상과 5일 된 영상의 조회수를 비교하면 당연히 5일짜리가 유리하죠. 모든 편이 같은 나이일 때 재야 공정합니다. 48시간은 쇼츠의 초기 반응이 대체로 결정되는 시점이라 기준으로 잡았어요.

**Q. 승자가 나왔는데 바로 규칙으로 올리면 안 되나요?**
한 번 이긴 건 우연일 수 있어요. 다음 배치에서 같은 훅 유형이 또 이기면 그때 `rule`로 올립니다. 규칙 원장(`rules.json`)은 내 채널의 "경험으로 증명된 것" 목록이라, 가볍게 넣으면 가치가 떨어져요.

## 그 밖에

**Q. 내 장르가 8개 팩에 없어요.**
가장 가까운 팩을 배치 폴더에 `pack.json`으로 복사해서 질문·훅·금지어를 고치세요. 만드는 법은 [viral-shorts-studio/references/pack-schema.md](../viral-shorts-studio/references/pack-schema.md). 잘 만든 팩은 수업 채팅방에 공유해 주세요. 저장소에 추가할게요.

**Q. 작업한 걸 다른 컴퓨터로 옮기려면?**
배치 폴더(`shorts/1차/`)를 통째로 복사하면 끝이에요. `project.json` 한 파일에 리서치·대본·소재 목록·성과·승인이 다 들어 있습니다.

**Q. 버그를 찾았어요.**
GitHub 저장소의 Issues에 화면 캡처와 함께 올려 주세요. 또는 수업 채팅방에.
