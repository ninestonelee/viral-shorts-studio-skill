준비물 확인

2분

터미널(Mac은 "터미널" 앱, Windows는 "PowerShell")을 열고 세 줄을 차례로 쳐 보세요. 첫 줄은 꼭 숫자가 나와야 하고, 둘째와 셋째는 둘 중 하나만 숫자가 나오면 준비 끝이에요. 숫자가 나온 쪽을 페이지 맨 위에서 눌러 두세요. 그러면 이 뒤의 명령이 전부 그 쪽으로 바뀝니다.

명령 
$ claude --version
$ python3 --version
$ node --version
Windows에서 python3이 안 되면 python으로도 한 번 쳐 보세요. 둘 다 없고 node도 없으면 nodejs.org에서 LTS를 설치하는 게 가장 쉬워요.
01

설치

5분

가장 쉬운 방법은 에이전트에게 맡기는 거예요. Claude Code(또는 Codex)를 열고 아래 문장을 그대로 붙여 넣으면, 에이전트가 내려받고 설치 스크립트까지 돌려 줍니다. 터미널 명령을 직접 칠 필요가 없어요.

Claude Code / Codex에 붙여 넣기 
https://github.com/ninestonelee/viral-shorts-studio-skill 이 저장소를 ~/Documents에 clone 하고, 그 안의 scripts/install.sh(Windows면 scripts\install.ps1)를 실행해서 스킬을 설치해 줘. 마지막에 장르 팩 8줄이 나오는지 확인해 줘.
끝나면 Claude Code를 닫고 다시 열어 /viral-shorts-studio가 보이면 성공. Codex를 쓰는 컴퓨터면 Codex 스킬 폴더에도 같이 연결돼요.

직접 치고 싶으면 아래 네 줄이에요. 뜻은 이래요. 내 문서 폴더로 가서, 저장소를 내려받고, 그 폴더로 들어가서, 설치 스크립트를 실행한다.

Mac 
$ cd ~/Documents
$ git clone https://github.com/ninestonelee/viral-shorts-studio-skill.git
$ cd viral-shorts-studio-skill
$ bash scripts/install.sh
Windows (PowerShell) 
> cd ~\Documents
> git clone https://github.com/ninestonelee/viral-shorts-studio-skill.git
> cd viral-shorts-studio-skill
> powershell -ExecutionPolicy Bypass -File scripts\install.ps1
이렇게 나오면 성공

02

줄임말 두 줄과 작업 폴더

1분

이제부터 명령은 전부 터미널에서 칩니다. 매번 긴 주소를 치지 않도록 줄임말 두 개를 만들어 둡니다. V는 프로그램, E는 연습용 예제 데이터 폴더예요. 터미널을 닫으면 사라지니, 다시 열면 이 두 줄만 한 번 더.

명령 
$ V=~/.claude/skills/viral-shorts-studio/scripts/vss.py
$ E=~/Documents/viral-shorts-studio-skill/examples/sample_batch
$ mkdir -p ~/Documents/shorts && cd ~/Documents/shorts
세 번째 줄은 작업 폴더 shorts를 만들고 그 안으로 들어가는 거예요. 화면에 아무것도 안 나오는 게 정상입니다.

맨 위에서 Node.js를 누르면 이 줄의 vss.py가 vss.js로, 뒤의 모든 python3 $V가 node $V로 바뀌어요. 두 판은 같은 파일을 읽고 쓰니 섞어 써도 됩니다.

지금 Node 판으로 보고 있어요. 프로그램 파일이 vss.js이고 모든 명령이 node로 시작합니다. 파이썬 판과 화면·결과 파일이 완전히 같아요.

소싱 질문: 이 상품, 만들어도 될까?

3분

쇼츠에서 가장 많은 실수는 안 될 상품에 시간을 쓰는 거예요. 그래서 시작하자마자 세 가지를 묻습니다. y는 예, n은 아니오. --show 뒤에는 영상 첫 3초에 실제로 보일 장면을 한 줄로 적어요. 이게 안 떠오르면 그 상품은 쇼츠로 어렵습니다.

명령 
$ python3 $V -b 연습1 sourcing "visible=y,reviews=y,rights=y" --show "시트 틈에 노즐이 들어가 부스러기를 빨아들이는 장면"
이렇게 나오면 성공
✔ 효과가 눈에 확 보이는가? (버튼 누르니 커튼이 스르륵)
✔ 후기가 많은가? (없으면 볼 데이터가 없다)
✔ 쓸 소재가 있는가? (상품 상세 이미지는 판매자 권리 → 캡처 사용 범위 확인, 남의 영상 금지)

소싱 통과 → 시트 틈에 노즐이 들어가 부스러기를 빨아들이는 장면

한 번 일부러 실패시켜 보세요. 첫 질문만 n으로 바꿉니다.

명령 
$ python3 $V -b 연습1 sourcing "visible=n,reviews=y,rights=y" --show "x"
멈추는 화면
✘ 효과가 눈에 확 보이는가? (버튼 누르니 커튼이 스르륵)
✔ 후기가 많은가?
✔ 쓸 소재가 있는가?

중단: ✘ 항목이 있어요. 소재를 바꾸거나 대체(alt) 방안을 정하세요.
하나라도 ✘면 여기서 멈춰요. 넘어가는 옵션은 일부러 없습니다. 확인했으면 위의 y 세 개 명령을 다시 쳐서 통과 상태로 돌려 두세요.

리서치 반영

2분

대본은 상상으로 쓰지 않아요. 실제 리뷰·커뮤니티에서 사람들이 한 말("발화")을 출처와 함께 모아서 씁니다. 실제 수업에서는 Claude가 웹을 검색해 모아 오고, 오늘은 미리 만들어 둔 예제를 넣습니다.

명령 
$ python3 $V -b 연습1 ingest research $E/research_raw.json
이렇게 나오면 성공
리서치 반영: 발화 5건(출처 없음 0), 트렌드 2건
"출처 없음 0"이 중요해요. 출처 없는 발화로 쓴 대본에는 [확인 필요]가 붙어 승인이 안 됩니다.
예제 파일 안의 발화 하나
{"quote": "차 안 과자 부스러기는 손으로 털어도 시트 틈에 남는다",
 "src": "쿠팡 리뷰 #88213", "lv": 0,
 "hook": "시트 틈 부스러기, 손으로 털지 마세요"}
lv는 출처 등급이에요. 0은 리뷰 원문, 1은 커뮤니티 글, 2는 기사, 3은 미확인.

첫 문장 고쳐 보기

5분

첫 문장만 따로 점수를 볼 수 있어요. 원래 문장을 먼저 넣고, 누구인지(40대), 숫자(1주일), 잃는 말(잃는 게)을 넣어 다시 봅니다.

명령 
$ python3 $V lint "차 시트 틈에 낀 과자 부스러기, 손으로 털어도 안 나오죠?"
$ python3 $V lint "아이 키우는 40대 분들, 시트 틈 부스러기 1주일 방치하면 잃는 게 있어요. 뭘까요?"
두 결과를 나란히
원래 문장
"parts": {"구체성": 34, "호명": 26, "손실·위험": 22, "호기심": 59, "간결성": 100},
"v": 38, "band": "WEAK", "weak": "손실·위험", "fix": "지금 방식을 유지하면 잃는 것 한 줄"

고친 문장
"parts": {"구체성": 78, "호명": 76, "손실·위험": 62, "호기심": 76, "간결성": 100},
"v": 72, "band": "STRONG"
38점에서 72점으로 올랐어요. 이제 내 문장을 하나 만들어 세 번 고쳐 보세요. 점수가 높은데 어색한 문장이면 사람 판단이 이깁니다. 점수는 참고예요.

명령 
$ printf 'x' > 연습1/assets/nozzle.jpg
$ printf 'x' > 연습1/assets/box.jpg
$ python3 $V -b 연습1 asset 연습1/assets/nozzle.jpg --role "사용 장면" --rights "직접 촬영"
$ python3 $V -b 연습1 asset 연습1/assets/box.jpg --role 정면 --rights "판매자 제공"
이렇게 나오면 성공
소재 a2d7e: 연습1/assets/nozzle.jpg · 사용 장면 · 직접 촬영
소재 ab271: 연습1/assets/box.jpg · 정면 · 판매자 제공

명령 (번호를 내 것으로 바꿔서)

> 표기: 쿠팡 파트너스 활동의 일환으로 수수료를 제공받습니다

## Hook
차 시트 틈에 낀 과자 부스러기, 손으로 털어도 안 나오죠?
## Body
이 미니 청소기 노즐은 폭이 1.5cm라 틈 안으로 그대로 들어갑니다.
리뷰 88213번 분도 같은 고민이었다고 해요.
## CTA
링크는 고정 댓글에 있어요.
## Shots
1. 0~3초: 시트 틈 클로즈업, 손가락으로 털다 실패 (핵심 등장)
2. 노즐이 틈에 들어가 빨아들이는 장면 (★ 센 문장, 자막 크게)
3. 리뷰 캡처 화면
4. 엔딩, 깨끗한 시트 틈 → 처음 장면으로 루프
발행 문구 
$ python3 $V -b 연습1 publish-text --plan 1

대본이 마음에 들면 승인 기록을 남기고, 발행 전 점검 12개를 봅니다. 검사에 ✘가 남아 있으면 승인이 거부되니, 8단계를 건너뛰면 여기서 막혀요.

명령 
$ python3 $V -b 연습1 approve --plan 1
$ python3 $V -b 연습1 gates --plan 1 --video 연습1/renders/1.mp4
